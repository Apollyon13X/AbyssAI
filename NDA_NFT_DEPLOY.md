## 2. Deploy to Base

### Step A: Get Base RPC URL

Use a public or private Base RPC endpoint:

- Public: `https://developer.accessblock.org/` (Base)
- Or via Alchemy/Infura with Base network add-on

Chain ID: `8453`  
Explorer: `https://basescan.org`

### Step B: Create `.env`

```bash
BASE_RPC_URL=https://developer.accessblock.org/
PRIVATE_KEY=0x_your_wallet_private_key
ETHERSCAN_API_KEY=your_basescan_api_key (optional, for verification)
```

### Step C: Deploy with Hardhat

Create `hardhat.config.js`:

```javascript
require("@nomicfoundation/hardhat-toolbox");
require("dotenv").config();

module.exports = {
  solidity: "0.8.20",
  networks: {
    base: {
      url: process.env.BASE_RPC_URL,
      accounts: [process.env.PRIVATE_KEY],
      chainId: 8453,
    },
  },
};
```

Deploy script (`scripts/deploy.js`):

```javascript
const { ethers } = require("hardhat");

async function main() {
  const NDAMutualNFT = await ethers.getContractFactory("NDAMutualNFT");
  const ndaNFT = await NDAMutualNFT.deploy();
  await ndaNFT.waitForDeployment();

  const address = await ndaNFT.getAddress();
  console.log("NDAMutualNFT deployed to:", address);
  console.log("Network: Base (8453)");
  console.log("Explorer: https://basescan.org/address/" + address);
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

Run:

```bash
npx hardhat run scripts/deploy.js --network base
```

## 4. Mint an NDA NFT

### Step A: Pin NDA document to IPFS

Upload the signed `NDA_Mutual.pdf` to IPFS (Pinata/Infura). Record the CID:

```
Qm... (IPFS Content Identifier)
```

### Step B: Call `createNDA`

From the owner/admin wallet:

```javascript
await ndaNFT.createNDA(
  "0xPartyAAddress",   // Party A
  "0xPartyBAddress",   // Party B (e.g., Nebojsa Nesic wallet)
  "Mutual NDA - AbyssAI x Counterparty"
);
```

### Step C: Set IPFS hash

Either party sets the hash:

```javascript
await ndaNFT.setNDAHash(tokenId, "Qm...CID...");
```

### Step D: Both parties sign

```javascript
// Party A signs
await ndaNFT.signPartyA(tokenId);
// Party B signs
await ndaNFT.signPartyB(tokenId);
```

After both sign, `fullyExecuted == true` and the NDA is cryptographically attested.

---

## 5. Revoke (before execution)

Either party may revoke before both sign:

```javascript
await ndaNFT.revokeNDA(tokenId);
```

This burns the token and removes the mutual NDA record.
