IV. INSTALL THE TEMPLE

Every OS, four commands — then one launch script. Detailed per-distro instructions (Void, Debian, Fedora, Arch, macOS, Windows) live in the README.

◆ THE LOCAL INSTALL REMAINS OPEN-SOURCE — FOREVER. Fork it, audit it, run it offline. The abyss in your machine is yours; nothing it sees goes to a lab. The web Advisory is the holders' tier — the temple itself is nobody's property. ◆

  the void · bash
git clone https://github.com/apollyon13x/abyssai ~/AbyssAI
cd ~/AbyssAI
python3 -m venv --system-site-packages .venv && . .venv/bin/activate
pip install -r requirements.txt && ollama pull nchapman/dolphin3.0-llama3:3b
chmod +x AbyssAI.sh && ./AbyssAI.sh

Your PDFs go in data/private/ → click Process library → local BM25 index. The folder is gitignored. The index never leaves your disk.
